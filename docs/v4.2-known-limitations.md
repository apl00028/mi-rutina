# GymOS v4.2 — Limitaciones conocidas

- La importación moderna admite `.xlsx` y CSV. `.xls` se inspecciona de forma conservadora; macros antiguas no pueden validarse completamente en cliente y deben rechazarse cuando sean detectables o dudosas.
- Límite de importación de rutina: 5 MB, seis sesiones, 20 ejercicios por sesión y 100 ejercicios totales. Los encabezados ambiguos, fórmulas y macros bloquean la propuesta.
- Supabase Auth, sincronización, cambio de contraseña, correo, proveedor de IA y tablas remotas requieren conexión. Offline se conserva la experiencia local ya cacheada.
- XLSX y Supabase se cargan desde CDN. Tras una primera carga completa pueden existir en la caché HTTP del navegador, pero no forman parte del precache privado de GymOS. La importación XLSX y autenticación no se garantizan en una primera apertura offline.
- El service worker no cachea respuestas remotas ni privadas. Es una decisión deliberada de aislamiento; offline usa vault/localStorage.
- La recuperación, nutrición profesional, medidas y análisis requieren que sus tablas opcionales de Supabase estén instaladas para sincronización dedicada; si faltan, continúa el payload general/local cuando está implementado.
- `app.js` conserva deuda técnica como coordinador grande. No se extrajo navegación/renderizado en Fase I para evitar una reescritura de riesgo.
- Se mantiene compatibilidad A/B/C para datos antiguos. La identidad real es `sessionId`; no se crean claves D/E/F.
- No se implementa subida de fotografía de avatar.
- El JSON técnico de scoring no se muestra en la interfaz normal.
- La cobertura automatizada es amplia en Node, pero el navegador integrado no estuvo disponible durante la auditoría final. Quedan pendientes los recorridos manuales de viewport, lector/teclado, PWA real y Supabase configurado.
- La configuración real de Supabase debe mantener Redirect URLs, RLS y SMTP propios para producción. Los límites de correo dependen del proyecto.
- Navegadores objetivo: versiones actuales de Chrome/Edge/Safari móvil con APIs PWA estándar. La ejecución manual cruzada queda pendiente según el plan.
