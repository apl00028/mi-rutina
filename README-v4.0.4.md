# GymOS v4.0.4

Cambios:
- El botón **Salir** pasa a llamarse **Ya lo he realizado**.
- Al pulsarlo se guarda una marca persistente.
- El cuestionario deja de aparecer automáticamente al navegar por la aplicación.
- El perfil puede seguir abriéndose manualmente desde **Más → Perfil deportivo**.
- Completar el cuestionario normalmente mantiene las opciones de **Guardar solo perfil** o **Reemplazar rutina**.

No requiere cambios en Supabase ni ejecutar SQL.
